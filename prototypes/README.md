# Прототипы (до утверждения брифа)

- `vanilla-three/pallet-scene.js` — черновик 3D-сцены «груз на поддоне» на чистом Three.js (поддон EUR 1200×800, гофрокороба в 3 яруса, скотч, стреппинг, уголки, спиральная намотка стрейч-плёнки, разбор на слои). После утверждения брифа переносится в React Three Fiber.
- `drawings/*.svg` — изометрические технические чертежи (груз, рулон плёнки, рулон скотча, кабельный барабан, разрез гофрокартона). Генерируются `node tools/drawings/build.mjs`.
