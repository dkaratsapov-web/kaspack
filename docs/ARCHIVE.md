# Сохранённые сцены

## «Товары из коробки → конвейер» (выключена)

Закреплённый первый экран на десктопе: клапаны верхних коробов открываются, товары поднимаются из коробов,
подложка первого экрана растворяется, товары перелетают в карточки каталога, подъезжает заголовок,
и лента-конвейер листается влево. Снята с сайта по решению заказчика, код сохранён целиком.

**Как включить:** `lib/features.ts` → `HERO_HANDOFF = true`. Флаг возвращает класс `kp-pin` (Intro) и каталог-конвейер
(`components/sections/Catalog.tsx`) вместо сетки иконок (`CatalogGrid`).

Из чего состоит:
- `components/HeroCatalogStage.tsx` — общая закреплённая сцена, один rAF-цикл с пружиной, раскладка слоёв;
- `components/three/HeroHandoff.tsx` — подъём товаров из коробов (HeroRisers) и полёт в карточки (Flights);
- `components/three/StageDriver.tsx`, `lib/heroProgress.ts` — общий прогресс сцены;
- `components/sections/Catalog.tsx` — конвейер (лента, рама, стойки), спрайты вращения на наведении;
- стили `.kp-pin .stage-view`, `.conveyor-*`, `[data-wait]` в `app/globals.css`;
- превью и спрайты товаров — `public/catalog/*.webp` (их по-прежнему используют меню и страницы товаров).

Последний коммит, где сцена была включена на сайте: см. `git log -- lib/features.ts` (коммит перед введением флага).
