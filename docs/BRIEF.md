# KASPACK — бриф на редизайн сайта

Версия 1.1 · 11.10.2026 · статус: **решения заказчика собраны, ждёт финального ОК**
Проект: новый уникальный премиальный сайт для kaspack.ru на React (Next.js) с 3D-анимацией и сохранением/ростом конверсии.

Обозначения достоверности: 🟢 подтверждено источником · 🟡 найдено в одном источнике, нужно сверить · 🔴 моё допущение, требует решения заказчика.

### 1.5 Безопасность и побочные эффекты установленного (важно знать)
Вредоносного кода и инструкций-инъекций не найдено. Но:
- **jmrsquared-standards** через SessionStart-хук в каждой сессии подмешивает свои правила (yarn/tRPC/SST, скрытая смена стиля ответов, требование править `CLAUDE.md`), пишет `~/.claude/.jmr-active`, а скрипт картинок читает `~/.zshrc` в поисках ключей Unsplash/Pexels. **Рекомендую отключить плагин** (`claude plugin disable jmrsquared-standards@skills`), оставив только его аудитор, который можно запускать напрямую.
- **superpowers** через хук включает «HARD-GATE»: ничего не строить до одобрения дизайна. Это совпадает с нашим порядком «сначала бриф».
- **ui-ux-pro-max/design** (генерация логотипов) читает `~/.claude/.env` и ходит во внешние AI-API — только при явном вызове; не используем.
- **lume/scaffold.js** ставит `create-next-app@latest` без фиксации версии — не запускаем, каркас собираю сам с фиксированными версиями.

### 1.6 Ограничения скиллов для русскоязычного B2B
- **Кириллица**: многие рекомендуемые шрифты её не поддерживают (Bebas Neue, Archivo, Outfit, Barlow, Space Mono, Work Sans, Clash, Cabinet, Satoshi, General Sans). Берём только проверенные: Geologica + Onest.
- **Правило «ноль тире»** из англоязычных скиллов не переносим буквально: в русском тире грамматически обязательно. Запрещаем только декоративные конструкции «СЛОВО — фрагмент» в заголовках и кнопках; диапазоны пишем по-русски: «17–23 мкм».
- **headline_scorer** из copywriting не понимает русский (нормальный заголовок получил 30/100) — заголовки выбираем экспертно и через A/B.
- **SEO-скиллы ориентированы на Google/GA4** — адаптирую под Яндекс (Вебмастер, Метрика, Яндекс Бизнес, 2ГИС, региональность).

### 1.4 Как разрешены конфликты между скиллами

| Конфликт | Решение | Почему |
|---|---|---|
| LUME: кастомный курсор | ❌ не делаем | claude-web-skills: «AI tell», мешает B2B-пользователю, вредит доступности |
| LUME: прелоадер-«занавес» | ❌ заменяем на интро-анимацию поверх уже отрисованного контента | Прелоадер ухудшает LCP и конверсию; закупщик пришёл за ценой, а не за шоу |
| LUME: заголовки 8–20rem | ⚠️ умеренно: до ~6rem на десктопе | Заголовок должен влезть в 2 строки и не вытеснить CTA с первого экрана |
| LUME: тёмная тема «по умолчанию премиально» | Светлая «чертёжная бумага» + один тёмный блок-кульминация | Отличие от конкурентов, читаемость каталога, «технический паспорт» как метафора |
| LUME / bizarro: Lenis smooth-scroll | ❌ нативный скролл | cg-web-animate и claude-web-skills: нативный скролл по умолчанию, доступность, якоря |
| Easing выходов: ease-in (cg, animate) vs «никогда ease-in» (claude-web-skills) | Выходы UI — ease-out, на 25–40% короче входа; ускорение только для уходящих за экран | Отзывчивость без «вязкости» |
| bizarro: «не жертвовать анимацией ради LCP» | ❌ Core Web Vitals в приоритете | Органический трафик из Яндекса и конверсия важнее эффекта |
| 3D vs конверсия | 3D грузится **после** текста и CTA, лениво, с SVG-фолбэком | page-cro: ценность за 5 секунд и CTA без скролла важнее эффекта |

### 2.3 Проблемы старого сайта (выводы из индекса; подтвердить скриншотами)
1. **Шаблонные title** «X купить оптом от производителя в Твери - Kaspack» на всех страницах — SEO-рабочие, но без отличий; сохраняем формулу, улучшаем description.
2. **Противоречие Москва/Тверь** в текстах страниц (в тексте «продажа в Москве», в заголовках Тверь) — путает пользователя и поисковик.
3. **Нет доказательств**: в индексе не найдено отзывов, кейсов, логотипов клиентов, фото производства, года основания, мощностей.
4. **Нет цен и минимальных партий** — закупщику нечего сравнить, он уходит к конкурентам с прайсом (ppack.ru, cpereezd.ru показывают цены).
5. **Заявление «крупнейший производитель в РФ»** — юридический риск: ФЗ-38 «О рекламе» (ст. 5) запрещает превосходные степени без подтверждения. Рекомендую заменить на проверяемые факты.
6. **Неизвестные slug** «Гофротара» и «Ящики для продуктов» — нужен краулинг для 301-карты.

### 2.5 Разбор скриншота главной (получен от заказчика)

## 4. Позиционирование, оффер, тон

**Позиционирование**: «Производитель упаковки с инженерным подходом: всё для отгрузки груза в одном месте, напрямую из Твери, с доставкой по России».

**Ценностное предложение (5 секунд)**: что (упаковка для отгрузки) + кто (собственное производство) + где (Тверь → вся Россия) + как получить (расчёт от менеджера).

**Кандидаты заголовка hero** (финальный выбор за вами, оценю скриптом `headline_scorer` и A/B):
1. «Упаковка, которая держит груз» — эмоция + функция, связан с 3D-сценой ⭐ рекомендую (оценка экспертная: скорер copywriting не работает с русским)
2. «Всё для отгрузки груза от производителя в Твери» — максимум SEO и ясности
3. «Плёнка, короба, поддоны и ещё 13 видов тары от производителя»
4. «Упакуем отгрузку целиком: от поддона до плёнки»

**Подзаголовок**: «Собственное производство в Твери. Стрейч-плёнка, гофротара, поддоны и ещё 13 видов тары оптом с доставкой по России.»

**Тон голоса**: инженерный, спокойный, конкретный. Факты и размеры вместо эпитетов. Без «уникальных решений», «индивидуального подхода», восклицательных знаков. Обращение на «вы». Короткие предложения.

**Слова-запреты**: крупнейший, лучший, лидер (без доказательств — ФЗ-38), инновационный, качественный (без конкретики), индивидуальный подход.

## 5. Креативная концепция: «Груз в сборе»

**Design read**: редизайн-overhaul корпоративного B2B-сайта производителя для закупщиков, язык — «технический паспорт изделия», премиальный за счёт инженерной точности, а не роскоши.

**Шкалы (claude-web-skills)**: вариативность **7** · моушн **6** (3D-пики, остальное спокойно) · плотность **5** (каталог требует информации).

**Идея**: главный герой сайта — **3D-груз на европоддоне**: гофрокороба в три яруса, скотч на клапанах, стреппинг-лента, защитные уголки, стрейч-плёнка. **Каждый слой этого груза — товар Kaspack.** Сайт буквально показывает: «всё, из чего собрана ваша отгрузка, есть у нас».

**Решение 16 (максимум 3D):** четыре 3D-момента на одной общей сцене/рендерере: (1) hero — груз с намоткой плёнки; (2) «Груз в разборе»; (3) доставка — **фура в фирменных шевронах** заезжает в кадр по скроллу, в кузов «загружается» тот же груз; (4) каталог — вращаемые 3D-модели (рулон плёнки, барабан, короб, поддон с клеймом IPPC), подгружаются по наведению/тапу.

**Сигнатурный приём (то, чего нет ни у кого)**: блок «Груз в разборе». При скролле груз **разбирается на слои в 3D**: плёнка поднимается «чехлом», стреппинг отделяется, ярусы коробов расходятся, внизу остаётся поддон. У каждого слоя появляется выноска в стиле чертежа (название, ключевая характеристика, ссылка в каталог). В конце — CTA «Рассчитать заказ». Фраза, которую посетитель перескажет коллеге: «там коробка с плёнкой разбирается на части, и каждая часть — их товар».

**Второй визуальный язык — технические чертежи**: изометрические SVG-чертежи с размерными линиями (рулон плёнки, барабан, разрез гофрокартона, рулон скотча). Используются в каталоге, на страницах товаров, как фолбэк 3D. Это превращает отсутствие фотографий в стиль, а позже работает рядом с реальными фото.

**Кривая ощущений (journey)**:
| Бит | Что чувствует посетитель | Что на экране |
|---|---|---|
| 1. Узнавание | «Это про мою отгрузку» | Hero: груз, на который в реальном времени наматывается плёнка; заголовок + CTA |
| 2. Ясность | «У них есть всё нужное» | Каталог: 4 семейства, 16 категорий, чертежи, характеристики |
| 3. **Пик** | «Вот это да, и это всё у них» | Тёмный блок «Груз в разборе» (3D, scroll-scrub) |
| 4. Уверенность | «Сделают под меня» | «Под ваш груз»: размеры, логотип, сырьё, сборка |
| 5. Спокойствие | «Понятно, как это работает» | Процесс заказа: 4 шага + доставка |
| 6. Решение | «Оставлю заявку» | Ответы на возражения + форма расчёта + контакты |

Оливковый `#94B030` со старых кнопок убираем: один зелёный — лайм логотипа. Палитра отличается от конкурентов (синие и зелёные шаблоны) за счёт сочетания кислотного лайма с графитом. Это фирменная пара Kaspack, а не модный штамп.

### 6.2 Типографика (обе с кириллицей, self-hosted)
- **Geologica** (variable) — заголовки, 500–700, трекинг −0.02…−0.035em.
- **Onest** (variable) — текст и интерфейс, 400–600, `tabular-nums` для характеристик.
- Не используем Inter/Roboto (шаблонность), не используем шрифты с Google CDN (стабильность в РФ).

### 6.3 Сетка, формы, глубина
- Контейнер 1280–1440px, 12 колонок, на мобиле строго 1 колонка.
- **Радиусы: 2px везде** (индустриальная точность), без «таблеток».
- Тени: только у плавающих элементов (шапка после скролла, мобильная CTA-панель), тонированные.
- Иконки: Phosphor (одна толщина линии).
- Без: градиентного текста, неоновых свечений, «трёх одинаковых карточек», эйбрау над каждой секцией, «01/06» нумерации, декоративных «СЛОВО — фрагмент», mono-шрифта «для техничности», кастомного курсора.

### 6.4 Фото (что нужно снять — см. п. 15)
Документальная индустриальная съёмка: цех, экструдер стрейча, гофроагрегат, поддоны на складе, ваши машины, руки менеджера с образцами. Холодная цветокоррекция под палитру. Никакого стока с «улыбающимися людьми в касках».

## 7. 3D и моушн

### 7.1 Сцены
| Где | 3D/анимация | Технология | Фолбэк |
|---|---|---|---|
| Hero | Груз на поддоне; плёнка наматывается за ~2,5 с после загрузки; лёгкий поворот за курсором (пружина, только мышь); медленное «дыхание» | React Three Fiber + drei | SVG-чертёж с анимацией линий |
| Груз в разборе | Пин секции, разбор на 6 слоёв по скроллу, выноски-ссылки привязаны к 3D-точкам | R3F + GSAP ScrollTrigger (scrub) | Статичный «взрыв-чертёж» с подписями |
| Каталог | Смена чертежа при смене семейства (crossfade 200 мс) | Motion | — |
| Процесс | Линия маршрута рисуется по скроллу | GSAP / CSS scroll-timeline | Статичная линия |
| Страница товара | Интерактивный 3D-рулон/барабан, который можно покрутить (этап 2) | R3F | Чертёж с размерами |
| UI | Нажатие кнопки 0.97, раскрытия 180–250 мс, появления 500–700 мс один раз | CSS / Motion | — |

### 7.2 Правила, которые сохраняют конверсию
1. **LCP — это заголовок, а не 3D.** Текст и CTA рендерятся сервером; Three.js грузится лениво после первой отрисовки (`dynamic import`, idle).
2. **CTA никогда не перекрываются сценой** и видны без скролла на 1366×768 и 390×844.
3. **Бюджет**: 3D-чанк ≤ 250 KB gzip, DPR ≤ 1.75, рендер на паузе вне экрана и во вкладке в фоне; 60 fps на среднем ноутбуке.
4. **Мобильные**: облегчённая сцена (без теней, меньше полигонов), без пина, разбор проигрывается по мере прокрутки как обычная секция.
5. **prefers-reduced-motion** и отсутствие WebGL: чертежи вместо 3D, без автоповоротов.
6. Анимируем только transform/opacity/clip-path; easing `cubic-bezier(0.23,1,0.32,1)`; без бесконечных анимаций в UI.

## 9. Конверсия (page-cro + form-cro + psychology)

### 9.1 Главная конверсия и микро-конверсии
- **Макро**: заявка на расчёт (форма). Цель Метрики `lead_form_submit`.
- **Микро**: клик по телефону (`tel_click`), WhatsApp (`wa_click`), email (`mail_click`), открытие категории (`category_open`), досмотр «Груза в разборе» (`explode_complete`), клик CTA по местам (`cta_hero`, `cta_explode`, `cta_final`, `cta_sticky_mobile`).

### 9.2 CTA-стратегия
- Один основной ярлык на весь сайт: **«Рассчитать заказ»** (ведёт к форме); кнопка отправки — **«Получить расчёт»**.
- Повтор в точках решения: hero, после каталога, конец «Груза в разборе», финал, мобильная панель, каждая страница категории.
- Альтернативы для A/B: «Получить цену» / «Рассчитать стоимость» / «Узнать цену за 15 минут» (только если SLA реальный 🔴).

### 9.3 Форма (form-cro)
| Поле | Обязательность | Обоснование |
|---|---|---|
| Телефон | обязательно | Основной канал B2B в РФ; маска +7 |
| Имя | обязательно | Обращение менеджера |
| Что нужно (категория, мультивыбор чипами) | необязательно | Маршрутизация менеджеру, ускоряет расчёт |
| Объём / комментарий | необязательно | Расчёт без лишнего звонка |
| Согласие на обработку ПДн | обязательно (152-ФЗ) | Юридическое требование |

Итого 2 обязательных поля + согласие. Валидация при уходе с поля, ошибки конкретные («Введите телефон: 10 цифр после +7»), введённое не стирается. Рядом с кнопкой: **«Перезвоним за 15 минут в рабочее время (Пн–Пт, 9:00–18:00 МСК)»**; вне графика текст меняется на «Перезвоним в понедельник/завтра с 9:00». Заявка → почта info@kaspack.ru + Telegram-бот отдела продаж + сделка в amoCRM (с UTM и списком товаров).

**Итоговая схема форм (решение 6):** hero-форма (имя + телефон) · калькулятор (товары + объём + телефон) · «Заказать звонок» в шапке (один телефон) · форма дилера на `/partneram`. Все остальные кнопки ведут к калькулятору. Альтернатива форме — кнопки WhatsApp/звонок.

### 9.4 Доверие и возражения
Только реальные доказательства: реквизиты, год регистрации, адрес производства, фото цеха и автопарка, сертификаты/ГОСТ 🔴, логотипы клиентов с разрешения 🔴, отзывы с должностью 🔴. **Ничего не выдумываем** — это и правило скиллов, и требование ФЗ-38.

### 9.5 Психологические принципы (marketing-psychology)
- **Hick's law**: каталог разбит на 4 семейства вместо списка из 16.
- **Bundle / IKEA effect**: «Груз в разборе» подталкивает к комплексной закупке.
- **Снижение риска**: «заказ любого объёма», «персональный менеджер».
- **Social proof**: секция доказательств ближе к форме.
- **Без фейковой срочности** (таймеры, «осталось 3 рулона»).

### 9.6 Гипотезы A/B после запуска
1. Заголовок hero (вариант 1 vs 2). 2. Форма в hero (короткая, только телефон) vs кнопка. 3. Наличие «цен от» в каталоге. 4. Текст CTA. 5. 3D vs статичный чертёж в hero (проверяем, что 3D не снижает конверсию).

## 10. SEO и миграция (главный риск редизайна)

1. **Все 16 URL категорий сохраняются 1:1.** Для неизвестных slug — краулинг старого сайта (нужен сетевой доступ) и 301-карта.
2. Title по проверенной формуле + уникальные description; H1 = название категории.
3. Next.js **статический экспорт**: каждая страница — готовый HTML (Яндекс индексирует без JS).
4. Разметка schema.org: `Organization`, `LocalBusiness` (адрес, телефон), `Product`/`OfferCatalog` для категорий, `BreadcrumbList`, `FAQPage`.
5. `sitemap.xml`, `robots.txt`, canonical, Open Graph-картинка (рендер 3D-сцены).
6. Локальное SEO: Яндекс Бизнес, 2ГИС, единый NAP (имя-адрес-телефон).
7. Устранить противоречие «Москва/Тверь» в текстах.
8. До запуска: выгрузка позиций и трафика из Вебмастера/Метрики 🔴 для сравнения после.
