# Типовая страница товара

Шаблон один, контент у каждого товара свой: файл `lib/products/<slug>.ts` (тип `ProductPage`).
Вёрстка — `components/product/ProductTemplate.tsx`, маршрут — `app/[slug]/page.tsx`.
Пока товара нет в реестре `lib/products/index.ts`, его URL открывается упрощённым шаблоном (ничего не ломается).

## Структура страницы

| # | Блок | Фон | Что внутри | Поле конфига |
|---|------|-----|------------|--------------|
| 1 | Hero | bone | хлебные крошки, H1 + вторая строка, лид, 4 факта, 3D-модель (крутится пальцем/мышью), «Рассчитать стоимость», «Подобрать параметры», телефон | `hero` |
| 2 | Расчёт `#raschet` | graphite | гибкая форма под товар: поля из конфига + имя/телефон/согласие | `form` |
| 3 | Виды | bone | карточки «чем отличаются» (если у товара есть виды) | `types`, `headings.types` |
| 4 | Характеристики | bone | таблица по группам; те же строки уходят в JSON-LD `additionalProperty` | `specs`, `headings.specs` |
| 5 | Как подобрать | lime | экспертный гайд в 3 шага — главный уникальный текст страницы; рядом короткая форма «Поможем с подбором» (имя + телефон) | `guide` |
| 6 | Применение | bone | для чего нужен товар | `uses`, `headings.uses` |

## SEO

- **title / description** — свои у каждого товара (`seo`). Title сохраняет формулу старого сайта (миграция без потери позиций).
- **H1** — название товара; ключ «оптом от производителя» во второй строке (`hero.kicker`).
- **H2** — свои формулировки под запросы товара (`headings`), не склейка «Характеристики {товара}».
- **keywords** — ориентир для текстов, в мета-теги не выводятся.
- **canonical** `https://kaspack.ru/<slug>`, Open Graph с картинкой товара.
- **JSON-LD** (`@graph`): `BreadcrumbList`, `Product` (бренд Kaspack, производитель ООО «Каспак», характеристики; без `offers`, пока нет цен), `FAQPage`. Organization — общий на весь сайт.
- **Уникальность**: гайд, виды, FAQ и применение пишутся под каждый товар. Нельзя копировать тексты между страницами — иначе тонкий контент.
- **Только факты**: в контент попадают подтверждённые данные (бриф, старый сайт, заказчик). Нет цифры — пишем качественно, не выдумываем.

## Гибкая форма

Поля задаются в `form.fields` и идут в две колонки парами; `wide: true` (и любая textarea) — на всю строку. Обязательны только имя, телефон и согласие; всё про товар необязательно. Варианта «Подскажите» в чипах нет: не знаете — просто не отмечаете, менеджер уточнит.

```ts
{ id: 'type', label: 'Вид', kind: 'chips', options: ['Ручная', 'Машинная'] }      // один вариант
{ id: 'uses', label: 'Для чего', kind: 'chips', options: [...], multiple: true }                // несколько
{ id: 'width', label: 'Ширина', kind: 'number', unit: 'мм', hint: '125–500 мм' }               // число с единицей
{ id: 'volume', label: 'Объём', kind: 'number', units: ['рулонов', 'паллет'] }                 // число + выбор единицы
{ id: 'size', label: 'Размер', kind: 'text', placeholder: '600×400×400' }                      // строка
{ id: 'comment', label: 'Что упаковываете', kind: 'textarea' }                                  // уходит в комментарий
```

В заявку менеджеру параметры приходят парами «Поле: значение» (`details`), textarea — комментарием.
Сервер (`server/lead-server.mjs`) принимает до 12 пар и комментарий до 600 символов.

## Как добавить товар

1. Скопировать `lib/products/strejch-plenka.ts` в `lib/products/<slug>.ts`, slug — как в каталоге (`lib/content.ts`).
2. Переписать весь контент под товар: seo, hero, headings, поля формы, виды, характеристики, гайд, применение, FAQ.
3. Добавить в `PAGES` в `lib/products/index.ts`.
4. `npx tsc --noEmit && npx next build`, проверить страницу, JSON-LD — в Rich Results Test.
